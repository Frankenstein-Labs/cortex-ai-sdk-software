# Complete upstream source snapshots

This directory contains complete source snapshots of the two upstream projects used as Cortex engine references. These are full repositories, not reduced engine excerpts.

- `openhands-software-agent-sdk/` — complete OpenHands Software Agent SDK repository.
- `open-design/` — complete OpenDesign repository, including its daemon, web, desktop, skills, plugins, design systems, tests, and documentation.

The Cortex-owned integration layer remains under `engines/` and will be developed separately. Do not edit upstream-derived code without preserving the original license and recording the change.
